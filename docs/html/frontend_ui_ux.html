Frontend UI / UX Enhancements

The frontend is built for a highly immersive, premium user experience that aligns strictly with the Raymond Gray brand identity and engineering discipline.

01 · Branding & Typography

Branding & Typography

  • Subdomain Branding Style: Implements the distinct "Raymond Gray | Vehicle Services" branding format next to the logo in both the TopNav and Footer, ensuring visual consistency across the organization's properties.
  • Premium Typography: Advanced CSS grids tailored for premium readability, utilizing custom fonts (Gotham and Montserrat).
02 · Responsive Navigation & Mobile-First Developments

Responsive Navigation & Mobile-First Developments

  • Dynamic TopNav: An interactive top navigation bar that responds to scroll progress.
  • Section Navigation: A sticky SectionNav for in-page jumping. On mobile devices, the SectionNav automatically collapses into a sleek dropdown menu to preserve screen real estate.
  • "Back to Top" Action: A globally accessible floating action button appears seamlessly on mobile and desktop views when scrolled past 500px, allowing instant return to the top of the page.
  • Mobile Optimizations: Touch-optimized targets, horizontal mobile carousels, and responsive padding adjustments ensuring safe areas (e.g., iPhone notches) are respected on modern mobile browsers.
03 · Footer Design & Layout

Footer Design & Layout

  • Custom Grid Architecture: Features a heavily customized, responsive multi-column CSS grid.
  • Optical Cap-Height Alignment: Includes precise typographical adjustments—such as utilizing an 80px top margin on desktop non-primary columns—to ensure that small UI headings perfectly optical-align with the large branded typography and logos on wide screens.
04 · Interactive Elements

Interactive Elements

  • Galleries & Carousels: Visual showcases of workshop standards and infrastructure setups using drag-friendly carousels.
  • Animated Data Reveals: Smooth entrance animations (via MotionProvider) are applied to headings, statistics strips, and feature blocks as the user scrolls, creating a dynamic storytelling experience.
